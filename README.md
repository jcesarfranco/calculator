# Calculadora Simples

Uma calculadora web simples e responsiva construída com HTML, CSS e JavaScript.

## Descrição

Este projeto é uma calculadora funcional para operações básicas, incluindo:

- Soma
- Subtração
- Multiplicação
- Divisão
- Porcentagem
- Troca de sinal (+/-)
- Ponto decimal
- Limpeza e remoção do último valor

A interface foi desenvolvida para ser simples, limpa e fácil de usar em desktop e dispositivos móveis.

## Funcionalidades

- Operações matemáticas básicas
- Suporte a números decimais
- Botão de limpar tudo (AC)
- Botão para apagar o último caractere (DEL)
- Conversão de porcentagem
- Alternância entre número positivo e negativo
- Layout responsivo

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
